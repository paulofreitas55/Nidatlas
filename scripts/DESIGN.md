# Nidatlas — Design Direction

Aesthetic: modern field guide meets collector's album. Calm colors,
playful structure.

Layout — the atlas is a CARD GRID, not a list:
- Species render as compact cards in a responsive grid (left-to-right,
  wrapping), grouped under Order → Family section headers
- Each card: dex-style number (#001–#584, taxonomic sequence), thumbnail
  placeholder (square, top of card), scientific name (serif, italic),
  Portuguese common name below it
- Family sections feel like "boxes" — a labeled container holding its cards
- No infinite undifferentiated scroll: collapsible order/family sections
  and a sticky quick-nav (jump to order) make exploring feel deliberate

Colors & type:
- Light paper-like background; dark green primary; one warm accent
  (ochre/terracota) used sparingly
- Serif for species names (scientific in italic); clean sans elsewhere
- No gradients, no heavy shadows, no hero sections

Mobile-first: cards reflow to 2 per row on phones; search stays reachable.
