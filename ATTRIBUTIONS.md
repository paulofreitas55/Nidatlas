## Unverified — flagged for follow-up

- **GBIF vernacular names licence granularity.** The two formal GBIF downloads (species list, occurrence cube) are explicitly filtered to CC0/CC-BY records only (excluding CC-BY-NC), per `scripts/prepare_cube.py` and the equivalent species-list filter. The vernacular names pulled live via `scripts/fetch_vernacular_names.py`, however, come from GBIF's species API with **no equivalent per-record licence filter** — that endpoint returns whatever GBIF's backbone has aggregated (checklists, Catalog of Life, etc.) without a per-name licence field the script checks. I could not confirm whether any individual vernacular name in `data/vernacular_cache.json` carries a CC-BY-NC (non-commercial-only) source. This should be checked against GBIF's `vernacularNames` response fields (`source`, `sourceTaxonKey`) before treating the site's commercial-use posture as fully clean.
- **BioCLIP 2 training data licence, TreeOfLife-200M.** Reported as CC0 per public sources, but I did not independently verify this against Imageomics' own dataset documentation — it doesn't affect Nidario's own licence position (we only consume the released model weights, not the training set), so it's noted here for completeness rather than as a blocking concern.
